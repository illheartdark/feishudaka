## 1. 这是什么

飞书打卡助手：在 Android 手机上提供

- 白天：进入/离开打卡范围时的通知提醒；
- 夜间：23:55 自动打当天最后一张下班卡、0:00 自动打新一天上班卡（无障碍点击，仅在仍在范围内时执行）；
- 本地记录与状态展示，不联网、不调用飞书 API。

## 2. 构建方式（离线，无 Gradle）

本机无 Gradle、无 Android Studio、无外网，故采用 SDK 自带工具链直接构建：

```powershell
.\build.ps1
```

脚本流程：`javac` 编译 → `d8` 转 dex → `aapt2 link` 打包资源与清单 → `jar` 并入 classes.dex → `zipalign` 对齐 → `apksigner` 签名。

产物：`..\realise\飞书打卡-v<versionName>.apk`（调试签名，版本号取自 `AndroidManifest.xml`）。按 `agent.md`（1）规则 15，**APK 只能存放在 `realise\`**，构建脚本会把中间 APK 与 `.idsig` 副产物清理掉，最终只保留该文件。

依赖：JDK 17、Android SDK（platforms/android-35、build-tools/35.0.0）。

## 4. 源码职责

| 类 | 职责 |
|---|---|
| `Constants` | 配置键、默认值、动作常量 |
| `GeofenceEngine` | 距离判定与滞回（进 20 m / 出 35 m，连续 3 次） |
| `DayStateStore` | 今日上班卡/下班卡状态、最近一次结果 |
| `Notifier` | 通知渠道与各类提醒文案 |
| `LocationTracker` | 原生 LocationManager 采样（GPS + 网络），记录精度 |
| `TrackService` | 前台服务：定位、围栏、触发提醒、调度夜间任务 |
| `TriggerScheduler` | 精确闹钟：下一个 23:55 与 0:00 |
| `AlarmReceiver` | 到点执行：判断是否仍在范围内 → 调用打卡执行器 |
| `BootReceiver` | 开机自启恢复服务 |
| `PunchExecutor` | 打卡编排：影子模式、无障碍检查、拉起飞书、重试、通知结果 |
| `PunchAccessibilityService` | 无障碍服务：打开飞书并点击「打卡」控件，读取结果 |
| `MainActivity` | 状态页与配置（设工位、测试打卡、影子模式开关） |

## 5. 运行要求（华为 HarmonyOS 4.3）

| 项 | 设置路径 |
|---|---|
| 定位权限 | 应用 → 权限 → 位置 → 始终允许 + 精确位置 |
| 通知权限 | 应用 → 通知 → 允许 |
| 无障碍服务 | 设置 → 辅助功能 → 无障碍 → 打卡助手 → 开启 |
| 应用启动管理 | 设置 → 应用 → 应用启动管理 → 打卡助手 → 关闭自动管理，勾选自启动/关联启动/后台活动 |
| 电池优化 | 设置 → 电池 → 更多电池设置 → 打卡助手 → 不限制 |
| 任务锁定 | 最近任务 → 下拉打卡助手卡片加锁 |
| 纯净模式 | 安装 APK 前临时关闭 |

## 6. 安全与边界

- 影子模式默认开启：只记录「本该打卡」而不实际点击，验证判定准确后再关闭。
- 不伪造定位、不 root、不修改飞书客户端。
- 位置与记录仅存本机，不上传。
